- Bhubaneswar (101 categories, 1020 businesses)
- Cuttack (101 categories, 1010 businesses)
- Puri (101 categories, 1010 businesses)
- Rourkela (101 categories, 1010 businesses)
- Sambalpur (101 categories, 1010 businesses)

Total: 6000+ businesses with names, addresses, phone numbers, ratings, reviews, hours and descriptions.

Features:
- Multi-city selector
- Search across all businesses
- Category filtering and sorting
- Responsive mobile-friendly design
- SEO content for each category
- Custom logo and favicon
